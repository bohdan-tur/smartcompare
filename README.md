# SmartCompare: інтерактивний прототип (ЛР3, «Людино-машинна взаємодія»)

Сервіс порівняння оголошень вживаних iPhone. Покупець додає 2–3 посилання (OLX, Prom), бачить їх у таблиці, отримує позначки розбіжностей і прогалин, складає питання продавцю й обирає кандидата.

**Прототип:** відкрийте сторінку GitHub Pages цього репозиторію (папка `docs/`).

## Що є
- Сценарій 1: додати скільки завгодно оголошень → попарне порівняння: у таблиці двоє, слабшого відкидаєте свайпом угору або кнопкою «Відкинути», на його місце приходить наступний з черги; хто лишився, той кандидат.
- Сценарій 2: «Що уточнити» → зняти зайві питання → скопіювати для продавця.
- Помилки й крайові випадки: порожнє поле, не посилання, інший сайт, дубль, зняте оголошення, скасування відкидання, повернення відкинутих, повторне натискання під час завантаження.
- Світла і темна тема, розмір тексту 100 / 115 / 130 % у налаштуваннях, мобільна версія на весь екран, клавіатурна навігація.

## Дизайн-система
Кольори, відступи, радіуси й текстові стилі взято з Figma Variables проєкту (`tokens.json`, `src/tokens.css`). Компоненти відповідають бібліотеці «03 Компоненти» у Figma.

## Як зібрано
React 18 + Vite. Дані захардкоджені в `src/data.js`, бекенду немає.
Код згенеровано за допомогою Claude Code (Anthropic) на основі макетів і токенів з Figma; використання AI описано в AI-лозі звіту.

```
npm install
npm run dev     # локальний запуск
npm run build   # збірка в dist/
```
Після змін скопіюйте `dist/index.html` у `docs/index.html`.
